# Quellen-Bibliothek

Wiederverwendbare, geprüfte Quellen. Ein Fakt, der hier **belastbar** steht, kann ohne erneute
Recherche in einen Post — die postspezifische `sources.md` verlinkt dann hierher.

## Konvention

- Eine Datei je Quellenraum, z. B. `ai-act.md`, `arbeitsmarkt.md`, `datenschutz-arbeitsrecht.md`.
- Jeder Eintrag: **Aussage · Primärquelle (Link/Fundstelle) · Datum · Belastbarkeit · Stand der Prüfung**.
- Belastbarkeit: `belastbar` (Primärquelle oder mehrfach unabhängig bestätigt) | `ungeprüft`.
- **Primärquellen zuerst:** EUR-Lex, Bundesagentur für Arbeit, Statistisches Bundesamt, Gesetzestexte.
  Presse/Aggregatoren nur als Zeiger auf das Original.
